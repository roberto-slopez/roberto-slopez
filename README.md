## Selected engineering work

### Clinical software and real-time imaging

I designed the architecture for an electronic health record platform, with Django microservices running on AWS Fargate behind an API gateway. The Vue interface uses interactive anatomy maps to help clinical staff select areas of the body. I also built a gastroscopy viewer that streams images and video over Socket.IO, and a concurrent Rust CLI for bulk medical data migration.

**Tools** · Python, Django, Vue, PrimeVue, Socket.IO, Rust, AWS Fargate, Docker, Terraform

### E-commerce with a RAG assistant

I built a Laravel storefront with a product catalog, promotions, coupons, and a cart. On the admin side, I integrated a retrieval-augmented generation (RAG) assistant that combines pgvector search with tool calls for order analysis. The platform also includes analytics dashboards and automated reporting.

**Tools** · PHP, Laravel, PostgreSQL, pgvector, RAG

### Banking systems and legacy modernization

At Plus Technologies & Innovations, I migrated critical services from .NET Framework to .NET 6 and 8 and reworked shared libraries and dependency injection. The modernization delivered a **300%+ performance improvement on critical services**. I also built a shared query layer for Oracle, PostgreSQL, and SQL Server, helped migrate legacy SWIFT systems, and led work on PCI DSS certification and PCI SSF renewal.

**Tools** · C#, .NET, LINQ, SqlKata, Oracle, PostgreSQL, SQL Server, Azure DevOps

### Applied machine learning and automation

I worked with data scientists to extract training datasets from core banking systems, build interfaces for training workflows, and run model inference with ONNX Runtime. I integrated explainable AI to make model outputs easier to review. My consulting work also includes Go APIs for credit applications and automated data extraction with Puppeteer and Playwright.

**Tools** · Go, Python, ONNX Runtime, PyTorch, TensorFlow, Puppeteer, Playwright
